\section{Phase 1: Initial research and Planning}

This phase will be a phase to focus on research for tools that can help for the development of the SwayLayoutManager project, also we will be planning the design and architecture of the project, by this I mean the actual code implementation structure, the modules that will compose the project, and how they will interact with each other.

\subsection{Objectives}

\begin{itemize}
    \item Research existing tools and libraries that can facilitate interaction with Sway and Wayland.
    \item Propose a design and architecture for the SwayLayoutManager project.
    \item Create a plan with expected deadlines for the next phases of the project.
\end{itemize}

This phase won't last long since the heavy part for the command implementation is already defined in the proposal document. The main goal is to see if there is a more acurate way to implement commands reather that interact with \texttt{swaymsg} so we can can improve performance and reliability.

As mentioned in the proposal document, the programming language selected for the project CLI is Go, this can be changed if we find a better alternative during this research phase.
