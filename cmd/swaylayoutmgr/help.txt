Sway Layout Manager 0.1.0-dev
Manage and restore Sway window layouts

Usage:
  swaylayoutmgr <command> [arguments]

Commands:
  save <name>    Save current layout as a preset (auto-generates name if not provided)
  load <name>    Restore a saved layout preset
  list           List all saved layout presets
  delete <name>  Delete a saved layout preset

Options:
  --version, -v  Show version information
  --help, -h     Show this help message

Examples:
  swaylayoutmgr save my-workspace     # Save current layout with custom name
  swaylayoutmgr save                  # Save with auto-generated name
  swaylayoutmgr load my-workspace     # Restore a saved layout
  swaylayoutmgr list                  # Show all available presets
  swaylayoutmgr delete my-workspace   # Remove a saved preset

Notes:
  - Layout restoration preserves container hierarchy (tabbed, stacked, split)
  - Applications are relaunched in their original workspaces and positions
  - Floating windows and fullscreen states are restored
  - Supports Flatpak, Snap, and native applications
