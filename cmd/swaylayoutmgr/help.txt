Sway Layout Manager 0.1.0-dev
Manage and restore Sway window layouts

Usage:
  swaylayoutmgr [flags] <command> [arguments]

Commands:
  save [name]    Save current layout as a preset (auto-generates name if not provided)
  load <name>    Restore a saved layout preset
  list           List all saved layout presets
  delete <name>  Delete a saved layout preset

Flags:
  --skip-workspace=<id>[,<id>...]   Skip workspaces by number or name (comma-separated)
  --only-workspace=<id>[,<id>...]   Include only specified workspaces (comma-separated)
  --focus-workspace=<id>            Focus specified workspace after restoration
  --ignore-floating                 Ignore floating windows (not saved or restored)
  --export=<directory>              Export layout to specified directory (save only)
  --import=<directory>              Import layout from specified directory (load only)
                                    Quote workspace names with spaces
  --overwrite                       Overwrite existing preset without confirmation
  -h, --help                        Show this help message
  -v, --version                     Show version information

Notes:
  - Layout restoration preserves container hierarchy (tabbed, stacked, split)
  - Applications are relaunched in their original workspaces and positions
  - Floating windows and fullscreen states are restored
  - Supports Flatpak, Snap, and native applications
